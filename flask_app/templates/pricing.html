Complete Wireless Hardware

One wireless setup for every building height.

Every current SaleWell setup uses a wireless tank node and a pump-side controller. No long sensor signal cable is needed between the tank and motor area.

Tank side Wireless Tank Sensor Node

A powered smart sensor stays close to the tank and sends live water-level readings directly to the controller over ESP-NOW.

  • No long sensor signal cable
  • Accurate local level readings
  • No external Wi-Fi router required
Pump side Wireless Pump Controller

The main controller stays near the pump panel, receives fresh tank readings wirelessly and manages automation and alerts.

  • Automatic and remote pump control
  • Fail-safe motor OFF on stale data
  • Relay/contactor safety integration
Complete system Wireless Smart Tank Kit

The tank node, pump controller and phone dashboard work together as one complete wireless monitoring and control system.

  • Live level, pump status and alerts
  • Expandable to source and extra tanks
  • Standard setup for homes and multi-floor sites
The tank-to-controller data link uses ESP-NOW. Home Basic and Home Control need no external router or internet, but each device still needs suitable power, a verified ESP-NOW signal path and electrician approval for relay/contactor wiring.
