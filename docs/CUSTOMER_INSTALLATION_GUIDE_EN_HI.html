SaleWell Smart Tank

Easy Customer Installation Guide · आसान ग्राहक इंस्टॉलेशन गाइड

Use this guide to understand what will be installed and how the system is checked. Electrical work must be completed by a qualified electrician.

यह गाइड समझाती है कि कौन-सा सामान लगेगा और सिस्टम की जाँच कैसे होगी। बिजली का काम केवल योग्य इलेक्ट्रीशियन से करवाएँ।

Important / जरूरी: Switch OFF mains power before panel work. Do not connect the pump directly to the SaleWell controller. The controller operates the approved contactor/control circuit only.
पैनल पर काम करने से पहले मेन बिजली बंद करें। पंप को SaleWell कंट्रोलर से सीधे न जोड़ें। कंट्रोलर केवल सही कॉन्टैक्टर/कंट्रोल सर्किट को चलाता है।

2. Electrical panel connection / इलेक्ट्रिकल पैनल कनेक्शन

Existing motor starter panel + SaleWell pulse relays / मौजूदा स्टार्टर पैनल + SaleWell पल्स रिले

For qualified electrician only / केवल योग्य इलेक्ट्रीशियन के लिए
Simple rule / आसान नियम: START relay connects to the contactor START-control path. STOP relay connects to the contactor STOP-control path. The existing contactor continues to switch power to the pump.
START रिले कॉन्टैक्टर के START कंट्रोल मार्ग से जुड़ता है। STOP रिले कॉन्टैक्टर के STOP कंट्रोल मार्ग से जुड़ता है। पंप की पावर मौजूदा कॉन्टैक्टर ही चालू-बंद करता है।

Simple rule / आसान नियम: SaleWell only presses START or STOP electronically for about 500 ms. It does not carry motor power.
SaleWell केवल लगभग 500 ms के लिए इलेक्ट्रॉनिक START या STOP करता है। मोटर की पावर SaleWell से होकर नहीं जाती।
What happens? / क्या होता है?
START: SaleWell gives a short START pulse. The contactor and holding contact keep the pump running.
स्टार्ट: SaleWell छोटी START पल्स देता है। कॉन्टैक्टर और होल्डिंग कॉन्टैक्ट पंप को चालू रखते हैं।
STOP: SaleWell briefly opens the safety path. The contactor releases and the pump stops. A new START is needed to run again.
स्टॉप: SaleWell सुरक्षा मार्ग को थोड़ी देर खोलता है। कॉन्टैक्टर छूटता है और पंप बंद हो जाता है। दोबारा चलाने के लिए नया START जरूरी है।

NC = normally closed / सामान्य स्थिति में बंद · NO = normally open / सामान्य स्थिति में खुला
Physical buttons, overload and all safety interlocks must continue to work. / फिजिकल बटन, ओवरलोड और सभी सुरक्षा इंटरलॉक काम करते रहने चाहिए।

Current flow: START and STOP / करंट प्रवाह: स्टार्ट और स्टॉप

Bright, thick wires show the energized path. Grey wires have no current. These diagrams show the functional control path; AC current changes direction continuously.
चमकीली मोटी वायर उस मार्ग को दिखाती है जिसमें करंट है। धूसर वायर में करंट नहीं है। यह कंट्रोल का कार्यात्मक मार्ग है; AC करंट की दिशा लगातार बदलती है।

1. Pump START command / पंप स्टार्ट कमांड

Flow / प्रवाह: Control phase → STOP → overload → IoT STOP → IoT START pulse → coil → return. The contactor closes and motor current reaches the pump. / कंट्रोल फेज → STOP → ओवरलोड → IoT STOP → IoT START पल्स → कॉइल → रिटर्न। कॉन्टैक्टर बंद होकर मोटर को करंट देता है।

2. Pump STOP command / पंप स्टॉप कमांड

Flow / प्रवाह: Current reaches the opened IoT STOP contact and cannot continue to S1. The coil releases, the holding contact opens, and all three motor-power wires are disconnected. / करंट खुले IoT STOP कॉन्टैक्ट तक पहुँचकर रुक जाता है। कॉइल छूटती है, होल्डिंग कॉन्टैक्ट खुलता है और मोटर की तीनों पावर वायर कट जाती हैं।

4. Easy installation steps / आसान इंस्टॉलेशन स्टेप्स

1Site check / साइट जाँच

Show the installer the tanks, pump, panel, water source, power point, and Wi-Fi/mobile internet availability if required by the selected plan.
इंस्टॉलर को टैंक, पंप, पैनल, पानी का स्रोत, बिजली और चुने हुए प्लान के लिए जरूरी Wi-Fi/मोबाइल इंटरनेट की उपलब्धता दिखाएँ।

2Sensor fitting / सेंसर फिटिंग

The sensor is fixed above water, pointing straight down and away from inlet splash or obstacles.
सेंसर पानी के ऊपर सीधा नीचे की ओर और इनलेट की छींट या रुकावट से दूर लगाया जाता है।

3Controller fitting / कंट्रोलर फिटिंग

The controller is fitted in a dry place near the pump panel. The electrician connects it to the approved control circuit.
कंट्रोलर पंप पैनल के पास सूखी जगह लगता है। इलेक्ट्रीशियन इसे सही कंट्रोल सर्किट से जोड़ता है।

4Setup / सेटअप

Tank height, capacity, start level, stop level, device ID, and included app access are configured.
टैंक की ऊँचाई, क्षमता, स्टार्ट/स्टॉप स्तर, डिवाइस ID और ऐप एक्सेस सेट किए जाते हैं।

5Safety test / सुरक्षा टेस्ट

Check level reading, automatic start/stop, dry-run protection, manual OFF, alerts, and installed valves.
लेवल, ऑटो स्टार्ट/स्टॉप, ड्राई-रन सुरक्षा, मैनुअल OFF, अलर्ट और लगे वाल्व जाँचें।

6Handover / ग्राहक को सौंपना

Save the device ID and support number. Learn Auto/Manual mode, app access, and emergency OFF.
डिवाइस ID और सपोर्ट नंबर रखें। Auto/Manual मोड, ऐप और इमरजेंसी OFF समझें।

Correct Upper Level Sensor position / अपर लेवल सेंसर लगाने की सही जगह

Mount above the water, point straight down, and keep the path clear of inlet splash, pipes, ladders, float valves, and walls.
सेंसर को पानी के ऊपर सीधा नीचे की ओर लगाएँ और इनलेट की छींट, पाइप, सीढ़ी, फ्लोट वाल्व तथा दीवार से दूर रखें।

✓ Auto mode tested / Auto मोड टेस्ट हुआ
✓ Pump stops at maximum level / पंप अधिकतम स्तर पर बंद होता है
✓ Dry-run/source-empty protection tested, if included / शामिल होने पर ड्राई-रन सुरक्षा टेस्ट हुई
✓ Manual OFF works / मैनुअल OFF काम करता है
✓ Alerts received, if included / शामिल होने पर अलर्ट मिला
✓ 3-Way Motorized Valve tested, if included / शामिल होने पर मोटर वाल्व टेस्ट हुआ
✓ Manual operation demonstrated / मैनुअल उपयोग समझाया गया
✓ No exposed wire or water entry / खुला तार या पानी का रिसाव नहीं
✓ Mobile App/dashboard opens if included / शामिल होने पर ऐप खुलता है
✓ Device ID is recorded / डिवाइस ID लिखा है
